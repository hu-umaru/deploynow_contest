# Score remix / v2 設計

## 1列ごとの測定

各小節4列、4小節で16列。1列の時間は60/BPM秒。状態ベクトルは実部・虚部のFloat64Array各32要素です。`simulateColumn`で1列のユニタリを作用させ、`measureStep`でBorn確率に従って同時サンプリングします。

手描きモードでは、小節の先頭は0、それ以外は前列で測定された整数を入力とします。各整数から基底状態を準備して次の列を計算するので、これは射影測定でコヒーレンスが失われた状態の正しい更新です。毎拍「未測定の回路prefixを計算し直す」実装ではありません。

楽譜モードでは毎列元の音符から再準備します。各拍の高音順最大5音をq0〜q4に割り当て、0からXでそのマスクを作ります。実装の`basisState(mask)`はこのX準備と同値です。前拍のランダムな変化が以後のメロディを壊し続けないよう、手描きモードと明確に分けています。

プレビューは`previewSequence`で、各測定結果の分岐を確率で合成します。具体的には出力jの確率は Σ_i P(入力=i) × |U_ji|²。測定を挟んだ振幅は足しません。一般に混合状態となるため、単一の振幅位相針は表示しません。確率表示は固定演奏の実測値ではなく理論アンサンブルです。

H / M / HではP(1)=1/2のまま。Rz / Mも基底入力や基底混合入力の確率を変えません。干渉を残すINTはH-Rz-Hを測定なしで1列内に実行し、PAIRはH-CNOTを測定なしで1列内に実行します。CNOTは従来どおり単独の制御反転で、もつれを無条件に生むと説明しません。

## 楽譜変換

MusicXMLはブラウザのDOMParserで非圧縮score-partwiseを読みます。DOCTYPEの外部リソースを取得しません。内部エンティティは拒否します。2MBの上限を設け、音符上限も設けています。XMLをinnerHTMLには流し込みません。

divisionsとdurationから四分音符単位に換算。chordは直前音符と同じ開始位置、backup/forwardで多声部を整列。staff/voice/音高でタイを接続し、休符で時間を進めます。各パートで小節を整列し、先頭16拍の音符を保存。通常小節は拍子長と内容の長い方、implicitの弱起小節は実際の長さを採用します。

制限：score-timewise、圧縮MXL、PDF/OCR、MIDIは未対応。transpose、微分音、複合的な拍子表記はエラー。装飾・ペダル・反復展開・強弱の完全再現は対象外。複数テンポは最初の値のみ。原曲という表示は読み込めた先頭16拍の音符による合成再生を意味し、原録音の忠実再生ではありません。

量子版は開始/終了を最寄り整数拍へ丸め（開始+1拍を最短終了とする）、各拍の有効音高を重複排除して高音優先で5本に置きます。空き線には主旋律のオクターブ、完全5度、長3度等の固定候補を重複なしで補います。これは量子アルゴリズムによる和声推定ではなく、明示した音楽マッピングです。無音の拍ではC4近傍を候補にしますが、量子ゲートなしでは全線0なので鳴りません。

五線は固定された5音ではなく、各拍の5つの候補音を担います。セルに音名、元の音の準備にX→を表示。量子効果がない「変換のみ」でも丸め・上限5音・再発音による違いは生じるため、変換による違いと量子ゲートによる違いをUIとREADMEで区別します。

## 音声と比較

同じマスター音量・音色・BPMを使い、原曲は保持した拍時刻と音長、量子版は毎拍の結果からイベントを作ります。交互再生は16拍ごとに原曲→量子版→原曲。原曲再生時に測定を行ったような表示はしません。

音声クロックを基準に25ms周期・150ms先読みで**1拍ずつ**予約。UIタイマーにも拍と再生モードを渡します。停止・設定変更・バックグラウンド時に予約音、UIタイマー、スケジューラーを解除します。非同期AudioContext.resumeと停止の競合は世代番号で防ぎます。

ピアノ風シンセは基音・2倍音・3倍音と減衰エンベロープの合成音で、生ピアノのサンプルではありません。和音は1拍で同時発音、アルペジオは選ばれた全音を1拍内に分散します。

## 保存・移行

version 2にはsource=nullまたは{title, notes, warnings}、16測定値またはnullを保存します。各音の音高・時刻・長さ・音量、ゲートの占有、値域・数値の有限性を検証。ピッチ候補は保存音符から再生成し、外部から偽の候補マップを持ち込みません。

version 1は回路・音楽設定を残してversion 2へ移行。4つの旧固定測定値は破棄し、16拍に水増ししません。作品を上書きする操作はUndoで戻せます。非同期楽譜読込中に新しい編集が行われた場合、その編集を優先して古い取り込みを中止します。

IndexedDB書き込みは350msデバウンス・直列化。保存成功を最新の更新番号と照合します。起動時の読み込み前は編集を無効化。保存不可でもJSON書き出しで持ち出せます。データはサーバーへ送信しません。

## 検証

- 量子ゲートのユニタリ性・Born同時抽選・ビット順。
- 列ごとの状態崩壊、次列への引継ぎ、小節頭リセット、混合分岐の確率。
- INT/PAIR内部では測定を挟まないこと。
- 楽譜のクロマチック音高、5音上限、休符、量子効果なしの再現、原曲の小数拍。
- version 1移行、source検証、16測定値の保存。
- Chromiumで実MusicXML入力、DOMParserのタイ・和音・多声部・テンポ、A/B交互再生、拍ごとのUI、編集・保存・スマートフォン幅。

実機音質、Safari/iOS、長時間利用はCIの代替にならないため、確認範囲を区別して記録します。
