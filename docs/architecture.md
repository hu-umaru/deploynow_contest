# MVP設計

## 境界

`app.js` がUIを管理し、`quantum.js` と `project.js` はDOMに依存しない純粋なロジックとしてテストできます。音声と保存はそれぞれ `audio.js` と `storage.js` に分離しました。ランタイム外部依存・外部音源・外部フォント・計測APIはありません。

## 量子モデル

5量子ビットの状態を32個の複素数（実部・虚部それぞれFloat64Array）で持ちます。HとXは振幅対の更新、Rzは対角位相、CNOTは制御ビットが1の基底の入れ替えです。ゲート数Gに対する計算時間は O(G × 2^5)、状態メモリは O(2^5)。乱数はBorn確率からの同時測定にのみ用います。

毎小節リセットする仕様を採用し、小節の確率プレビューが前のランダムな結果に依存しないようにしています。測定後の状態を次の小節へ引き継ぐモードは未実装です。

相関を説明するときは、CNOTだけでもつれが発生すると断言しません。例えば `|00000⟩` にCNOTだけを作用させても状態は変わりません。プリセットではHで重ね合わせを作ってからCNOTを適用します。

右の小さな位相針は各基底の複素振幅の偏角です。物理的には相対位相が重要で、全体の共通位相は測定確率に影響しません。確率が1e-10以下の状態は上位一覧に表示しません。

## 音声

4拍で1小節、BPMの範囲40〜180。Web Audioの音声クロックを基準に25ms周期・150ms先読みで小節を予約します。小節内の発音はOscillatorNodeで事前予約します。UIの小節切替は対応時刻のタイマーで表示します。停止時には予約済みノード、UIタイマー、スケジューラーを解除します。音声初期化の非同期処理には世代番号を持たせ、開始直後の停止や二重操作の競合を避けます。

バックグラウンドへ移ると停止し、ブラウザのタイマー抑制による再開時の音の集中を避けます。数値で音量を制限し、マスターコンプレッサーを通します。再生中の回路・音楽設定の編集は停止して適用し、古い演奏スナップショットとUIが混在しないようにしています。

## 保存

スキーマversion=1。作品名、BPM、スケール、演奏形式、音色、音量、4小節分のゲート、任意の4測定値を保存します。読み込みでは列・量子ビット範囲、CNOTの異なる制御/標的、有限の角度、占有領域の重複、録音ビットの範囲を検証します。ゲート以外の追加フィールドは破棄します。

自動保存は350msのデバウンスと書き込み直列化を行い、最新の更新番号に対応する保存が成功した時だけ保存済みと表示します。起動時は保存データを読み終えるまで編集を無効にし、読み込みとの競合を避けます。保存できなくても作曲とJSON書き出しは使えます。未保存データがある状態で閉じる場合はブラウザ標準の確認を出します。

Undo/Redoは60世代のプロジェクトスナップショット。音量スライダーの連続操作は履歴に積みません。

## 初版の範囲と次の候補

- 実装済み：4小節、5量子ビット、4ゲート列、3プリセット、2音色、JSON保存。
- 未実装：WAV/MIDI書き出し、共有URL、作品一覧・複数保存、ドラッグ操作、量子実機接続、クラウド保存。
- 次の候補：実機での音質と操作感の調整、WAV/MIDI出力、測定後状態の引き継ぎモード。
- 想定利用：教育と音楽の探索。量子優位性の主張や暗号学的乱数生成を目的としません。
